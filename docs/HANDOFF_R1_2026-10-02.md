## 4. 步骤与验收

### S1 环境与模型锁定

- 用 uv 加入 `midigpt[inference]==0.3.4`。项目 Python 为 3.12，官方 wheel 支持 3.10–3.12 与 macOS arm64。若与现有依赖（如 torch）冲突，记录冲突并停下说明，不要擅自改动其他依赖的版本。
- 下载并锁定三个权重文件：`yellow_small`、`yellow_medium`（final）和 `prism_medium`（当前快照）。用 `InferenceEngine.from_checkpoint(<本地路径>)` 加载，不用按名称解析最新快照的 `from_pretrained`。在 `data/models/MANIFEST.json` 记录文件名、HF revision、SHA-256 与下载日期。
- 冒烟测试：
  - 4 小节旋律 MIDI → 自回归生成一条新的 bass 轨；
  - 同一片段的 bar infill；
  - 分别记录冷启动与热请求耗时、实际设备（MPS 或 CPU）、峰值内存。
- 若用 HTTP 服务：`midigpt-http` 默认端口 8000，与 FLUX 后端冲突，需改用其他端口（如 3456）。R1 优先直接调用 Python API。
- **验收：** 同一输入与种子运行两次结果一致，或记录不一致的原因；耗时表；锁定清单。

### S2 开发任务集

- **来源：** 从 Lakh MIDI 或 Slakh2100 中筛选含 bass（GM 32–39）和鼓、4/4、和弦清楚的流行／摇滚作品。BabySlakh 小样本可用于快速开始，但要先核实它是否包含分轨 MIDI。POP909 只用于和弦识别验证，它没有 bass 和鼓。
- **片段：** 构造 20–30 个 4 或 8 小节片段，来自不同作品；每个片段保留旋律（可加鼓）作为 motif，删去 bass。
- **请求：**
  - 从真人 bass 计算意图（方法见 S3），据此构造无意图、单项、两项组合三类请求；
  - 另做一部分反常请求：借用和弦、转位低音、推拍或切分节奏、只改一个和弦。这类请求没有真人对照，只用于统计遵从度。
- **记录：** 按作品划分开发集；记录每个片段的来源文件、hash、起止小节、保留的轨，以及和弦来自识别还是人工标注。
- **验收：** `data/runs/R1_tasks/manifest.json` 和可复现的构造脚本；划分不跨作品。

### S3 属性函数与打分程序

- **代码位置：** 新代码放在 `research/intent/`，与旧 AMT 管线分开。建议模块如下，可按实现调整：
  - `chords.py`：移植 FLUX 和弦字典，与前端的类型和拼写保持一致；
  - `attributes.py`：属性函数，从一条声部计算和声、节奏、音域属性；
  - `verify.py`：按意图与容差打分，输出分项分数；
  - `tasks.py`：S2 的构造脚本。
- **和声：** 每个和弦起点处的 bass 音是否为该和弦的低音（含转位）；强拍和弦音比例是否落在真人声部的区间内；弱拍级进经过音不扣分；推拍允许提前一个八分音符以内。
- **节奏：** 与目标轨（如底鼓）的起音对齐比例；每小节音符数是否在档位内。
- **音域：** 音高是否在范围内。
- **底线：** 非空；不照抄上下文轨（含八度复制）；单声部不重叠；重复与静音惩罚。
- **无意图请求（C0）：** 另算 bass 与旋律在强拍上的协和度。
- **单元测试：** `tests/test_intent_*.py`，用手写小例子覆盖 C 与 C/E、小节内换和弦、经过音、推拍、持续低音、空输出、照抄。
- **验收：** `uv run pytest -q` 全部通过；真人 bass 在自己的意图上得分接近满分。

### S4 打分程序验证

1. **区分度：** 真人 bass 配真和弦与配其他作品的和弦，报告 AUC（暂定 ≥ 0.9）。
2. **钻空子：** 全音符根音、照抄引导轨、随机调内音等退化输出，在有节奏或密度意图时不能拿最高分。
3. **和弦识别：** 在 POP909 抽样上与人工标注比对，报告根音与类型的一致率（暂定 ≥ 80%）。
4. **与人一致性：** 伦理获批前只做自评。Hanze 给 20–30 个片段的"和声贴合度"打分，报告与打分程序的秩相关，并注明是自评。

- **验收：** 验证结果写入证据说明。未达暂定阈值时记录原因并缩小意图类型，不要为了通过而调参。

### S5 C0–C2 基线

- **条件：**
  - C0：只给 motif；
  - C1：加推断出的和弦轨作为引导轨。先让模型给旋律生成一条钢琴轨，再用和弦识别读成和弦轨；生成后删除引导轨；
  - C2：原生控制（prism 的逐小节音级集合、音域、密度等）加 pitch mask 与 rhythm mask。
- **运行：** 每个请求、每个条件跑 3 个种子，保存全部输出与失败。
- **报告：**
  - 按意图类型、组合、典型或反常分组报告遵从度；
  - 记录非空率、退化输出率与耗时；
  - 整理失败类型，例如转位低音和小节内换和弦这类预期失效。
- **验收：** 结果表，以及 6–10 个代表性听例（含失败例），全部用统一音源渲染。
